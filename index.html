HV Components

Живая библиотека независимых интерфейсных модулей. Минимум кода — максимум ясности.

📘 О проекте

HV Components — это коллекция автономных UI‑модулей, написанных на чистом JS и SCSS без зависимостей. Каждый компонент можно использовать отдельно, а документация и playground‑страницы позволяют быстро протестировать и интегрировать его в любой проект.

🧩 Компоненты

  • Header — универсальный хедер
  • Modal — система модальных окон
  • Accordion — контентные аккордеоны
  • Form — все необходимые элементы форм

⚙️ Структура проекта

components/
├ hv-header/
├ hv-modal/
├ hv-accordion/
└ hv-form/

Каждый компонент включает JS, SCSS и README с документацией и примерами.

🚀 Идеология

Компоненты HV строятся на принципах автономности, прозрачности и воспроизводимости. Всё можно понять, не открывая исходники — логика заложена прямо в HTML. Цель проекта — сформировать минималистичный, понятный и живой UI‑фреймворк без избытков.
